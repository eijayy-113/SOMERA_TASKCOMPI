# Fieldnotes — Student Activity Compilation

A responsive compilation website presenting three separate student web activities. Open `index.html` in a modern browser to start exploring.

## Activities

- **Personal portfolio — `portfolio.html`:** introduction, education, skills, sample work, and contact.
- **Product marketplace — `market.html`:** a desk-goods storefront concept with product cards and a working demo cart. Nothing is sold and there is no checkout.
- **Responsive mobile web app — `bloom.html`:** a plant-care dashboard with responsive tabs, sample plant notes, and checkable daily tasks.

## Project files

- `index.html` — compilation home page with navigation, hero, three featured activity cards, and an about section.
- `portfolio.html`, `market.html`, `bloom.html` — the three completed activities.
- `styles.css` — shared design system, page layouts, responsive breakpoints, and focus states.
- `app.js` — marketplace demo cart and accessible Bloom app tabs/task states.
- `GITHUB_LINK.txt` — link to the public project repository.

## Notes

All pages use semantic HTML5, separate CSS and JavaScript, and relative paths between local pages. Layouts adapt to mobile, tablet, and desktop widths. Product imagery is loaded from Unsplash; the rest of the project does not require a build step or third-party JavaScript. The name, school, and contact shown in the portfolio are generic example content; personalize them before presenting.
